#1渠道生态·店中店合作终止

美国

Ulta Beauty 与 Target 结束店中店合作，会员积分与账户关联同步退出（A级）

信号判断：

Ulta 失去的是 Target 的高频综合零售入口，Target 失去的则是成熟的专柜品牌组合与跨平台会员体系。美妆品牌在 Target 的生意逻辑将由“借 Ulta 店中店完成高端化和会员转化”转为“进入 Target 自有高端空间并适配其独立的品牌、导购与奖励机制”；对希望以美国大众零售切入的品牌，渠道评估重点应转向 Target Beauty Studio 的首批品牌结构、到店服务兑现和 Target Circle 美妆激励规则，同时维持 Ulta 自营渠道的专业零售覆盖。

8月16日起，Ulta Beauty at Target 合作终止；Ulta 发送给会员的交易通知明确，当日起在 Target 购买合资格 Ulta Beauty 商品不再累积 Ulta Beauty Rewards 积分，Target Circle 与 Ulta Beauty Rewards 的账户关联也将取消。该邮件同时说明，既有 Ulta Beauty Rewards 账户及已累积积分仍可在 Ulta Beauty 门店、Ulta.com 和应用端使用。Ulta Beauty 会员通知存档：终止日期、积分与账户关联变化

此次退出早有双方协议基础：Ulta 与 Target 于2025年8月共同公告，双方将不续签在2026年8月到期的店中店合作，并承诺在合作结束前维持商品供应与过渡支持。Target 与 Ulta 联合公告：合作到期与过渡安排 Target 已披露，作为承接方案的 Target Beauty Studio 计划于2026年秋季在600多家门店及线上推出，并引入80多个全球、高端及新兴品牌，其中60多个为首次进入 Target 的品牌。Target Beauty Studio 公告：门店规模、品牌引入与服务配置

#2渠道生态·高端百货会员运营

中国香港

连卡佛 Beauty Stamp Card 2.0 到期，三店美妆消费激励完成一轮闭环（B级）

信号判断：

高端百货的美妆会员机制仍以线下交易为核心，再用电子钱包、社媒关注与体验礼遇提升复访。品牌若参与同类机制，需评估礼遇成本、柜台服务承接与可沉淀的会员数据，而非只看满赠带来的短期客单。

8月16日，连卡佛 Beauty Stamp Card 2.0 的累积及奖品选择期结束。官方条款明确，活动覆盖 IFC、海港城和时代广场门店的美妆及健康品类；会员单笔净消费每满500港元可获得1枚电子印花，达到不同印花档位可选择礼遇，交易登记和奖品选择均须在8月16日或之前完成。Lane Crawford 官方活动条款：活动截至日、门店和累积规则

#3其他动态·美妆数字化能力

全球

Perfect Corp 美妆与皮肤 AI 应用黑客松截稿，开放虚拟试用与皮肤分析 API 原型验证（B级）

信号判断：

美妆数字化竞争正在延伸到“可快速接入的能力层”。对品牌和零售商，试用、肤质评估与个性化推荐的差异化会更多体现在数据治理、结果解释、内容与商品链路的整合质量，而不只在单个算法功能。

8月16日，Perfect Corp 举办的 YouCam API Skin AI & Apparel VTO Hackathon 截止提交。公司官方公告明确，该全球挑战赛自7月6日开放，向开发者提供 API credits，参赛作品可调用 AI 皮肤分析、彩妆虚拟试用、服装虚拟试穿等能力，奖金最高5,000美元。Perfect Corp 官方公告：赛程、开放能力与截止日期
